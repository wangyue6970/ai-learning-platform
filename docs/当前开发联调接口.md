# 当前开发联调接口

本文件记录当前已经实现、可用于前后端联调的接口。它不替代《接口文档.md》中规划的 V1 完整接口。

## 获取题目编辑详情

`GET /api/questions/{id}`

用于题目编辑页。返回题干、选项、正确答案和解析；刷题页面仍应调用不返回答案的题目列表接口。

```json
{
  "id": 12,
  "libraryId": 3,
  "questionType": "SINGLE_CHOICE",
  "stem": "负责进程调度的是？",
  "options": [
    { "optionKey": "A", "content": "文件系统", "sortOrder": 1 },
    { "optionKey": "B", "content": "调度程序", "sortOrder": 2 }
  ],
  "correctAnswer": ["B"],
  "explanation": "调度程序负责选择下一个运行的进程。"
}
```

## 保存题目编辑

`PATCH /api/questions/{id}`

用于保存题型、题干、选项、正确答案和解析。题目仍属于原学习库，不能通过此接口修改 `libraryId`。如果正确答案变更，后端会清除该题现有的错题连续答对状态。

```json
{
  "questionType": "SINGLE_CHOICE",
  "stem": "负责进程调度的是？",
  "options": [
    { "optionKey": "A", "content": "文件系统", "sortOrder": 1 },
    { "optionKey": "B", "content": "调度程序", "sortOrder": 2 }
  ],
  "correctAnswer": ["B"],
  "explanation": "调度程序负责选择下一个运行的进程。"
}
```

## 删除题目

`DELETE /api/questions/{id}`

删除题目后，MySQL 会依据外键级联自动删除其选项、作答记录和错题状态。成功时返回 `204 No Content`，即请求成功但没有 JSON 内容。
