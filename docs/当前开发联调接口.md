# 当前开发联调接口

本文件记录当前已经实现、可用于前后端联调的接口。它不替代《接口文档.md》中规划的 V1 完整接口。

## 图片导入、OCR、AI 草稿与人工确认

以下接口是当前已经在 Android 真机上走通的导入闭环。一个学习库可一次上传任意数量的图片；每张图片分别识别、生成草稿和确认，不会因另一张失败而丢失已有结果。

| 方法 | 路径 | 作用 |
| --- | --- | --- |
| POST | `/api/libraries/{libraryId}/import-batches` | multipart 上传一个或多个文件，创建导入批次和文件记录。字段名为 `files`。 |
| POST | `/api/libraries/{libraryId}/import-batches/files/{importFileId}/recognize` | 对一张图片执行 PaddleOCR，保存识别文字。 |
| POST | `/api/libraries/{libraryId}/import-batches/files/{importFileId}/structure` | 调用本机 Ollama LLM，将识别文字整理为题目草稿。 |
| GET | `/api/libraries/{libraryId}/import-batches/files/{importFileId}/drafts` | 获取当前图片产生的草稿，供用户查看。 |
| PATCH | `/api/libraries/{libraryId}/import-batches/files/{importFileId}/drafts/{draftId}` | 保存用户对题型、题干、选项、答案和解析的修改；只更新草稿。 |
| POST | `/api/libraries/{libraryId}/import-batches/files/{importFileId}/drafts/{draftId}/confirm` | 用户确认一题，将草稿事务性复制为正式题目。 |

文件状态：

```text
WAITING_RECOGNITION
→ RECOGNIZING
→ WAITING_STRUCTURING
→ STRUCTURING
→ WAITING_CONFIRMATION
→ CONFIRMED（草稿已正式入库）
```

失败状态为 `UPLOAD_FAILED`、`RECOGNITION_FAILED` 或 `STRUCTURING_FAILED`。失败只影响该文件，前端会展示原因；其他文件仍可继续处理。

### 草稿编辑请求示例

```json
{
  "questionType": "SINGLE_CHOICE",
  "stem": "负责选择下一个运行进程的是？",
  "options": [
    { "optionKey": "A", "content": "文件系统", "sortOrder": 1 },
    { "optionKey": "B", "content": "调度程序", "sortOrder": 2 }
  ],
  "correctAnswer": ["B"],
  "explanation": "调度程序负责从就绪队列中选择下一个运行进程。",
  "knowledgePoints": []
}
```

确认入库时，后端再次检查草稿属于当前学习库和当前导入文件、题干和选项不为空、答案属于选项、单选和判断题不含多个答案。确认动作使用数据库事务：创建正式 `question`、创建 `question_option`、草稿标为 `CONFIRMED` 必须全部成功；重复确认会被拒绝。

## 获取题目编辑详情

`GET /api/questions/{id}`

用于题目编辑页。返回题干、选项、正确答案和解析；刷题页面仍应调用不返回答案的题目列表接口。

```json
{
  "id": 12,
  "libraryId": 3,
  "questionType": "SINGLE_CHOICE",
  "stem": "负责进程调度的是？",
  "options": [
    { "optionKey": "A", "content": "文件系统", "sortOrder": 1 },
    { "optionKey": "B", "content": "调度程序", "sortOrder": 2 }
  ],
  "correctAnswer": ["B"],
  "explanation": "调度程序负责选择下一个运行的进程。"
}
```

## 保存题目编辑

`PATCH /api/questions/{id}`

用于保存题型、题干、选项、正确答案和解析。题目仍属于原学习库，不能通过此接口修改 `libraryId`。如果正确答案变更，后端会清除该题现有的错题连续答对状态。

```json
{
  "questionType": "SINGLE_CHOICE",
  "stem": "负责进程调度的是？",
  "options": [
    { "optionKey": "A", "content": "文件系统", "sortOrder": 1 },
    { "optionKey": "B", "content": "调度程序", "sortOrder": 2 }
  ],
  "correctAnswer": ["B"],
  "explanation": "调度程序负责选择下一个运行的进程。"
}
```

## 删除题目

`DELETE /api/questions/{id}`

删除题目后，MySQL 会依据外键级联自动删除其选项、作答记录和错题状态。成功时返回 `204 No Content`，即请求成功但没有 JSON 内容。
