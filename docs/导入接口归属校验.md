# 导入接口归属校验

本说明记录图片导入、Word 导入、识别任务和题目草稿接口的用户数据隔离规则。

## 需要登录的接口

以下接口均需携带：

```http
Authorization: Bearer {accessToken}
```

- 创建导入批次、查看最新批次
- 查看某个批次或文件的草稿
- 编辑、确认入库、丢弃草稿
- 手动触发图片/Word 的识别或生成题目

## 归属规则

每个 HTTP 请求先从 JWT 中取得当前用户，再验证 URL 中的学习库属于该用户。随后后端从数据库核对关联关系：

```text
导入文件 → 导入批次 → 学习库
题目草稿 → 导入文件 → 导入批次 → 学习库
```

因此，客户端伪造学习库、批次、文件或草稿编号，都不能读写其他用户的导入数据。

后台 OCR/LLM 队列不接受客户端请求；它只处理已经由通过权限校验的用户创建的导入任务。AI 只能生成草稿，仍需用户确认后才会写入正式题库。

## 失败结果

- 未登录、Token 无效或过期：`401 Unauthorized`，消息为“请先登录或重新登录”。
- 学习库不属于当前用户：`403 Forbidden`，消息为“无权访问该学习库”。
- 文件或批次不属于 URL 中的学习库：`400 Bad Request`，不会执行识别、修改、确认或删除。
