# **AI 学习平台 V1**

> PRD：从图片 / Word 资料到可刷题题库

> **文件定位：**本文件是 AI 学习平台 V1 的产品需求唯一事实来源。整体架构、技术实现和接口文档必须以本文件的产品范围与业务规则为准。

版本：V1.0（统一修订版）  |  适用端：React Native Android 优先  |  后端：Spring Boot 单体

## **1. 产品目标与范围**

一句话定义：用户把学习资料导入某个学习库，系统通过 OCR 和 AI 整理成可编辑题目草稿；用户确认后形成正式题库，并可按题型刷完整题库或错题集。

### **1.1 目标用户与核心闭环**

- 目标用户：需要整理题目图片或 Word 资料、为期末备考刷题的大学生。

- 核心闭环：注册登录 → 新建学习库 → 批量导入图片或一个 .docx → AI 生成草稿 → 用户确认 → 按题型刷题 → 错题连续答对两次移出。

- 学习库是数据隔离边界：题目、作答记录、错题状态、导入批次都属于一个学习库。

### **1.2 V1 不做什么**

不做提醒和推送、学习计划、学习统计和复杂报告、会员、班级协作、收藏系统、AI 聊天导师、AI 学习建议、iOS、复杂公式识别、PDF 导入。原型中若出现掌握度、统计图、通知或 AI 建议，只能作为视觉参考，不进入 V1 功能范围。

## **2. 资料导入规则**

### **2.1 支持的资料与容量限制**

| **资料类型** | **V1 规则** | **服务端可配置限制** |
| --- | --- | --- |
| 图片 | 一个批次可选择多张图片；AI 自动识别每张图中的全部题目。 | 最多 30 张；单张最多 10 MB；批次总大小最多 100 MB。 |
| Word | 一个批次只能选择 1 个 .docx 文件，不能和图片混传。 | 文件最多 30 MB；批次总大小最多 100 MB。 |
| 不支持 | .doc、PDF、复杂公式题。 | 客户端在选择阶段提示用户转换为 .docx 或更换资料。 |

> **说明：**数量和大小上限是 V1 的安全边界，不是产品卖点。服务端通过配置下发当前限制，客户端展示并在选择文件时预检查。

### **2.2 导入状态与确认规则**

| **位置** | **状态** | **含义** |
| --- | --- | --- |
| 客户端本地 | SELECTED / UPLOADING / UPLOAD_FAILED | 用于展示选中、上传中和上传失败；不写入服务端批次状态。 |
| 服务端批次 | PROCESSING | 已创建批次，文件正在 OCR / AI 处理中。 |
| 服务端批次 | READY_FOR_CONFIRM | 所有文件处理结束且均成功，存在待确认草稿。 |
| 服务端批次 | PARTIAL_SUCCESS | 部分文件成功并产生草稿，另有文件失败；可先确认成功草稿，再单独重试失败文件。 |
| 服务端批次 | FAILED / CANCELLED / EXPIRED | 没有可确认草稿、用户取消，或未确认草稿到期。 |

识别结果必须先保存为可编辑草稿。用户修改题干、选项、题型、答案、解析和知识点后，点击“确认并保存”才创建正式题目。AI 永远不能直接把题目写入正式题库。

### **2.3 临时文件与草稿清理**

| **场景** | **清理规则** |
| --- | --- |
| 用户取消导入 | 立即清理本批次所有未使用的临时原文件和草稿。 |
| 确认成功的文件 | 确认成功后立即清理已处理的原始图片或 Word 文件。 |
| 识别失败的文件 | 保留原文件 24 小时，供用户点击“重试”；超过 24 小时自动删除。 |
| 未确认的草稿 | 草稿及其所需临时原文件最多保留 7 天；到期后批次状态改为 EXPIRED 并自动清理。 |

## **3. 题目、刷题与错题规则**

### **3.1 题目管理**

- V1 支持单选、多选、判断三种题型。

- 用户可查看、编辑和删除正式题目；删除题目会删除该题的作答记录、错题状态和会话题目关联，不保留历史。

- 用户修改正确答案后：只影响修改后的新作答；历史作答记录不重新判定；该题当前错题连续答对次数重置为 0。每条作答记录保存提交当时的答案快照。

### **3.2 刷题**

用户先选择题目范围（完整题库或错题集），再选择题型（单选、多选或判断）。同一次练习不会混入不同题型。系统默认随机排序。

| **规则** | **V1 定义** |
| --- | --- |
| 会话冻结 | 创建练习会话时，后端固定本次题目 ID 列表和顺序；会话中错题状态变化不会重新抽题。 |
| 有效期 | 练习会话有效期 24 小时；用户退出后可在有效期内继续。 |
| 题目删除 | 会话进行中若题目被删除，客户端跳过该题并提示“题目已删除”。 |
| 防重复提交 | 每次答案携带 clientAnswerId；同一用户的相同 ID 只能生效一次。 |
| 答案保密 | 刷题开始和下一题接口只返回题干、题型与选项；正确答案和解析仅在提交答案后返回。 |
| 继续练习 | 用户进入刷题设置时，系统查找该学习库中尚未过期的活动练习会话；存在时可继续练习。 |

### **3.3 错题集**

| **作答结果** | **错题状态变化** |
| --- | --- |
| 答错 | 进入或留在错题集，连续答对次数归零。 |
| 错题第一次连续答对 | 仍在错题集，连续答对次数为 1。 |
| 错题第二次连续答对 | 移出错题集，状态为 MASTERED。 |
| 已掌握题再次答错 | 重新进入错题集，连续答对次数归零。 |

## **4. 账号、数据隔离与删除**

- 用户可注册、登录、刷新登录状态和退出登录。accessToken 有效期 2 小时；refreshToken 有效期 30 天。令牌失效后引导用户重新登录。

- 后端从 JWT 获取 userId，不能信任客户端传来的 userId。每个库内接口同时验证 userId 与 libraryId。

- 删除学习库前客户端二次确认。后端把学习库标为删除中，后台按“作答记录与错题状态 → 会话题目 → 题目与草稿 → 导入文件与批次 → 学习库”的顺序删除，并记录删除日志。

## **5. 页面范围与验收**

### **5.1 V1 页面**

登录/注册、学习库列表、新建/编辑学习库、学习库详情、导入资料、导入处理中、识别结果确认、题目管理、刷题设置、刷题页面、答题结果、错题集、我的。

### **5.2 必过验收场景**

1. 一个用户创建两个学习库，分别导入和刷题；两个库的题目、错题和作答记录完全隔离。

1. 一次选择 3–30 张图片，或一个不超过 30 MB 的 .docx；能看到每个文件的处理结果。部分失败时，可确认成功草稿并在 24 小时内重试失败文件。

1. 用户修改草稿正确答案并确认后，后续刷题按修改后的答案判定；历史作答不被重算。

1. 选择“完整题库 + 单选”后，会话只出现单选题；错题连续答对两次后移出错题集，中途答错归零。

1. 刷题开始接口不含正确答案；重复提交相同 clientAnswerId 不增加作答记录，也不重复改变错题状态。

## **6. 开发顺序**

学习库与本地题目练习 → 错题规则和练习会话 → 登录令牌续期 → 导入批次与草稿确认 → 图片 / .docx 解析 → OCR / LLM → Android 真机试用。每一个阶段都要在手机上走通真实流程后再进入下一阶段。
