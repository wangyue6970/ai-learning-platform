# 刷题接口归属校验

本说明记录作答和错题集接口已启用的用户数据隔离规则。

## 需要登录的接口

```http
Authorization: Bearer {accessToken}
```

- `POST /api/practice/answers`
- `GET /api/practice/wrong-questions/library/{libraryId}`

## 作答规则

提交答案时，后端依次执行：

1. 从 JWT 取得当前登录用户。
2. 确认请求中的学习库属于该用户。
3. 从数据库读取题目，确认题目真实属于该学习库。
4. 判定对错，并在同一事务中保存作答记录和更新错题状态。

题目答错会进入错题集；错题连续答对两次会移出错题集。权限校验失败时，后两步不会执行，数据库不会写入作答记录或错题数据。

## 失败结果

- 未登录、Token 无效或过期：`401 Unauthorized`，消息为“请先登录或重新登录”。
- 学习库不属于当前用户：`403 Forbidden`，消息为“无权访问该学习库”。
- 题目不存在，或题目不属于请求中的学习库：`400 Bad Request`，消息为“题目不存在或不属于该学习库”。
