# **AI 学习平台 V1**

> 供 React Native Android 客户端与 Spring Boot 后端联调

> **接口原则：**Base URL：/api/v1。所有示例均使用统一响应包；刷题相关接口在提交前绝不返回正确答案或解析。

## **1. 通用约定**

### **1.1 鉴权与响应**

除注册、登录、刷新令牌和应用配置外，接口均要求 Authorization: Bearer {accessToken}。后端从令牌取得 userId，不接受客户端 userId 作为权限依据。

```json
{"code":"OK","message":"success","data":{},"requestId":"req_01J..."}
```

| **枚举** | **取值** |
| --- | --- |
| questionType | SINGLE \| MULTIPLE \| JUDGE |
| practiceScope | ALL \| WRONG |
| processingStatus | PROCESSING \| READY_FOR_CONFIRM \| PARTIAL_SUCCESS \| FAILED \| CANCELLED \| EXPIRED |
| confirmationStatus | NOT_CONFIRMED \| PARTIALLY_CONFIRMED \| CONFIRMED |
| wrongState | NOT_IN_WRONG_SET \| IN_WRONG_SET \| MASTERED |
| importFileStatus | UPLOADED \| PROCESSING \| SUCCEEDED \| FAILED \| EXPIRED |
| jobStatus | PENDING \| RUNNING \| RETRY_PENDING \| SUCCEEDED \| FAILED |

### **1.2 分页格式**

```json
{"code":"OK","message":"success","data":{"items":[],"page":1,"pageSize":20,"total":128,"hasNext":true},"requestId":"req_01J..."}
```

学习库、导入历史、草稿、题目和错题列表统一支持 page、pageSize；默认 pageSize=20，最大 100。

## **2. 认证与应用配置**

| **方法** | **路径** | **说明** |
| --- | --- | --- |
| POST | /auth/register | 注册；请求体：email、password、nickname；返回令牌对与用户信息。 |
| POST | /auth/login | 登录；返回 accessToken（2 小时）和 refreshToken（30 天）。 |
| POST | /auth/refresh | 传 refreshToken，轮换并返回新的令牌对。 |
| POST | /auth/logout | 撤销当前 refreshToken。 |
| GET | /auth/me | 获取当前用户。 |
| GET | /app-config | 获取上传类型与容量限制。 |

```text
POST /auth/login  
{"email":"student@example.com","password":"Example_123"}  
  
{"code":"OK","message":"success","data":{"accessToken":"eyJ...","accessTokenExpiresIn":7200,"refreshToken":"rt_...","refreshTokenExpiresIn":2592000,"user":{"id":"u_001","nickname":"小明"}},"requestId":"req_001"}
```

POST /auth/register 请求体示例：{"email":"student@example.com","password":"Example_123","nickname":"小明"}

```text
GET /app-config  
  
{"code":"OK","message":"success","data":{"import":{"acceptedImageMimeTypes":["image/jpeg","image/png"],"maxImageCount":30,"maxImageBytes":10485760,"acceptedDocumentExtensions":[".docx"],"maxDocumentBytes":31457280,"maxBatchBytes":104857600}},"requestId":"req_002"}
```

## **3. 学习库**

| **方法** | **路径** | **说明** |
| --- | --- | --- |
| GET | /libraries?page=1&pageSize=20 | 分页获取当前用户学习库，包含题目数和待练错题数。 |

## **4. 导入批次、文件与草稿**

### **4.1 创建与查询**

| **方法** | **路径** | **说明** |
| --- | --- | --- |
| POST | /libraries/{libraryId}/imports | 创建导入批次。multipart：多张图片或一个 .docx，不能混传。 |
| GET | /libraries/{libraryId}/imports?page=1&pageSize=20 | 分页获取导入历史。 |
| GET | /imports/{importId} | 获取批次、逐文件状态、失败原因、可确认草稿数与过期时间。 |
| POST | /imports/{importId}/files/{fileId}/retry | 在失败文件保存期内重新处理该文件。 |
| DELETE | /imports/{importId} | 取消未确认批次并立即清理临时文件。 |

```text
POST /libraries/lib_001/imports  
Content-Type: multipart/form-data  
files=@page-01.jpg  
files=@page-02.jpg  
clientBatchId=8c8b7190-...  
  
{"code":"ACCEPTED","message":"import created","data":{"id":"imp_001","processingStatus":"PROCESSING","confirmationStatus":"NOT_CONFIRMED"},"requestId":"req_004"}
```

```text
GET /imports/imp_001  
  
{"code":"OK","message":"success","data":{"id":"imp_001","libraryId":"lib_001","processingStatus":"PARTIAL_SUCCESS","confirmationStatus":"NOT_CONFIRMED","confirmableDraftCount":18,"expiresAt":"2026-07-30T10:00:00Z","files":[{"id":"if_01","name":"page-01.jpg","status":"SUCCEEDED"},{"id":"if_02","name":"page-02.jpg","status":"FAILED","failureReason":"图片过于模糊","retryUntil":"2026-07-24T10:00:00Z"}]},"requestId":"req_005"}
```

PARTIAL_SUCCESS 明确表示可以确认成功文件产生的草稿；失败文件在 retryUntil 前可单独重试。若已经过期，重试接口返回 REUPLOAD_REQUIRED。

### **4.2 草稿编辑与确认**

| **方法** | **路径** | **说明** |
| --- | --- | --- |
| GET | /imports/{importId}/draft-questions?page=1&pageSize=20 | 分页获取草稿；响应 data 中返回 confirmToken 与 draftVersion。 |
| PATCH | /imports/{importId}/draft-questions/{draftQuestionId} | 编辑题干、选项、答案、解析、标签或 discarded。编辑后草稿版本递增。 |
| POST | /imports/{importId}/confirm | 确认当前所有未丢弃且有效的草稿；要求 confirmToken 和 clientConfirmId。 |

```text
GET /imports/imp_001/draft-questions?page=1&pageSize=20  
  
{"code":"OK","message":"success","data":{"items":[{"id":"dq_101","sourceFileId":"if_01","type":"SINGLE","stem":"题干","options":[{"key":"A","text":"选项 A"},{"key":"B","text":"选项 B"}],"answer":["B"],"analysis":"解析","discarded":false,"version":3}],"page":1,"pageSize":20,"total":18,"hasNext":false,"confirmToken":"ct_01J...","draftVersion":3},"requestId":"req_006"}
```

```text
POST /imports/imp_001/confirm  
{"confirmToken":"ct_01J...","clientConfirmId":"cc_2b1e..."}  
  
{"code":"OK","message":"confirmed","data":{"createdQuestionCount":18,"confirmationStatus":"PARTIALLY_CONFIRMED","remainingFailedFileCount":1},"requestId":"req_007"}
```

confirmToken 绑定当前草稿版本；草稿被编辑、丢弃或已确认后旧 token 失效。clientConfirmId 在同一用户下唯一，超时重试返回首次确认结果，不会重复创建题目。

## **5. 题目管理**

| **方法** | **路径** | **说明** |
| --- | --- | --- |
| GET | /libraries/{libraryId}/questions?page=1&pageSize=20&type=SINGLE | 分页题目管理列表；可按题型筛选。 |
| GET | /questions/{questionId} | 管理详情，可返回正确答案与解析。 |
| PATCH | /questions/{questionId} | 编辑正式题目。可只提交需修改字段：type、stem、options、answer、analysis、tags。若正确答案变更，重置该题当前错题连续答对次数。 |
| DELETE | /questions/{questionId} | 删除题目及其作答记录、错题状态和会话题目关联。 |

PATCH /questions/q_101 请求体示例：{"type":"SINGLE","stem":"负责进程调度的是？","options":[{"key":"A","text":"文件系统"},{"key":"B","text":"调度程序"}],"answer":["B"],"analysis":"调度程序负责选择进程执行。","tags":["进程调度"]}

## **7. 错误码与联调重点**

| **错误码** | **含义与客户端处理** |
| --- | --- |
| UPLOAD_LIMIT_EXCEEDED | 超过服务端配置的数量或大小；展示当前限制。 |
| UNSUPPORTED_DOCUMENT | 不是 .docx；提示用户转换格式。 |
| IMPORT_FILE_EXPIRED / REUPLOAD_REQUIRED | 失败文件超过 24 小时，要求重新创建导入批次。 |
| CONFIRM_TOKEN_INVALID | 草稿已变化或已确认；重新获取草稿后再确认。 |
| ANSWER_DUPLICATED | 相同 clientAnswerId 已处理；按首次结果展示。 |
| SESSION_EXPIRED | 练习会话超过 24 小时；创建新会话。 |
| FORBIDDEN | 用户无权访问该学习库/资源；返回学习库列表。 |
| NO_PRACTICE_QUESTIONS | 所选完整题库或错题集内没有该题型题目；客户端显示“当前范围内暂无可练习的该题型题目”。 |

所有错误响应都必须包含 code、message、data（可为空）和 requestId。日志、监控与客户端问题反馈使用 requestId 关联排查。
