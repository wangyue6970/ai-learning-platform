# 题目接口归属校验

本说明记录题目接口已启用的用户数据隔离规则。

## 需要登录

以下接口均需携带：

```http
Authorization: Bearer {accessToken}
```

- `POST /api/questions`
- `GET /api/questions/library/{libraryId}`
- `GET /api/questions/{id}`
- `PATCH /api/questions/{id}`
- `DELETE /api/questions/{id}`

## 归属规则

- 新建题目时，后端只允许向当前登录用户自己的学习库写入题目。
- 查看完整题库时，后端只返回当前用户自己的学习库中的题目。
- 查看、修改、删除某道题时，后端先从数据库读取该题真实的 `library_id`，再检查该学习库的 `owner_id` 是否等于当前登录用户。
- 客户端传来的学习库编号不能决定权限；即使有人修改请求参数，也不能访问别人的题目。

## 失败结果

- 未登录、Token 无效或过期：`401 Unauthorized`，消息为“请先登录或重新登录”。
- 已登录但题目或学习库不属于本人：`403 Forbidden`，消息为“无权访问该学习库”。

## 当前边界

本小步只完成题目 CRUD 和完整题库读取的隔离。提交答案、错题集、导入批次和草稿确认会在后续小步使用同样的归属校验。
