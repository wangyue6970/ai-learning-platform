# 当前认证接口

本文档只记录已经实现并经过自动 HTTP 测试的认证接口。

## 注册

`POST /api/auth/register`

请求体：

```json
{
  "username": "xiaoming",
  "password": "password123"
}
```

成功时返回 `201 Created`：

```json
{
  "id": 1,
  "username": "xiaoming"
}
```

安全规则：

- 不返回 `password` 或 `passwordHash`。
- 用户名会去除首尾空格，长度必须为 3 到 50 个字符。
- 密码至少 8 个字符、不能全为空白、UTF-8 编码不能超过 72 字节。
- 用户名不能重复。

当前边界：登录、JWT 和统一错误状态码尚未实现。
