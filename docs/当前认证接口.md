# 当前认证接口

本文档只记录已经实现并经过自动 HTTP 测试的认证接口。

## 注册

`POST /api/auth/register`

请求体：

```json
{
  "username": "xiaoming",
  "password": "password123"
}
```

成功时返回 `201 Created`：

```json
{
  "id": 1,
  "username": "xiaoming"
}
```

安全规则：

- 不返回 `password` 或 `passwordHash`。
- 用户名会去除首尾空格，长度必须为 3 到 50 个字符。
- 密码至少 8 个字符、不能全为空白、UTF-8 编码不能超过 72 字节。
- 用户名不能重复。

## 登录

`POST /api/auth/login`

请求体：

```json
{
  "username": "xiaoming",
  "password": "password123"
}
```

成功时返回 `200 OK`：

```json
{
  "accessToken": "eyJ...",
  "tokenType": "Bearer",
  "expiresInSeconds": 7200,
  "username": "xiaoming"
}
```

失败规则：

- 用户名或密码为空：返回 `400 Bad Request`。
- 用户不存在或密码错误：统一返回 `401 Unauthorized` 和“用户名或密码错误”；不区分是哪一项错，避免泄露账号是否存在。
- 响应绝不返回 `password` 或 `passwordHash`。

当前边界：登录接口已经签发 2 小时有效的 accessToken；下一步才会解析令牌，并用它限制学习库、导入和题目接口只能访问本人数据。
